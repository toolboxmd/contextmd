# contextmd Repository Instructions

Follow the installed AgentsMD global contract.

## Connected projects

ContextMD is one system with Chromeria, AgentsMD and Agent Observer.
Chromeria's `GLOSSARY.md` is the system glossary; this repository's
`GLOSSARY.md` keeps only ContextMD's own terms.

| Project | Repository | Glossary |
| --- | --- | --- |
| Chromeria (system glossary) | `toolboxmd/chromeria` | [`GLOSSARY.md`](https://github.com/toolboxmd/chromeria/blob/main/GLOSSARY.md) |
| AgentsMD | `toolboxmd/agentsmd` | [`GLOSSARY.md`](https://github.com/toolboxmd/agentsmd/blob/main/GLOSSARY.md) |
| Agent Observer | `toolboxmd/agent-observer` | [`GLOSSARY.md`](https://github.com/toolboxmd/agent-observer/blob/main/GLOSSARY.md) |

Model Router (`toolboxmd/model-router`) is retired; Chromeria's Prism absorbed it.

## Feature map

When a pull request adds, splits, merges or removes a part of ContextMD, or binds a new Issue to one, update [`docs/map.md`](docs/map.md) in that same pull request.
