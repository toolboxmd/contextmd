# Objective

Agents in daily use on all my machines stop relearning what earlier sessions already knew.

The Objective is complete when:

- A judge reviews real sessions on every machine and finds each moment an agent needed knowledge it did not get; every miss is acted on by its cause, and the misses where the knowledge was already stored keep falling.
- Served context arrives in about one second on average, at most 10,000 characters per turn.
- Agent Observer shows repeated user corrections and repeated instructions falling.

Non-goal: making it cheaper before it works.
